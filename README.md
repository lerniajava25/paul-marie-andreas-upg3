# paul-marie-andreas-upg3

Gruppuppgift i Systemarkitektur.

Projektet är ett REST API byggt med Jakarta EE 11 och JAX-RS.
Applikationen körs på WildFly och använder Java 21.

## Requirements

- Java 21
- WildFly 41.0.1.Final
- IntelliJ IDEA
- Git

Maven behöver inte installeras separat eftersom projektet använder Maven Wrapper.

## Getting Started

### 1. Clone repository

```bash
git clone https://github.com/lerniajava25/paul-marie-andreas-upg3.git
```

Gå sedan in i projektet:

```bash
cd paul-marie-andreas-upg3
```

Öppna projektet i IntelliJ.

Kontrollera att projektets SDK och Language Level är inställda på Java 21.

### 2. Install WildFly

Ladda ner WildFly 41.0.1.Final och packa upp servern på valfri plats utanför projektet.

Exempel på Windows:

```text
C:\wildfly\wildfly-41.0.1.Final
```

WildFly ska inte läggas till i projektet eller Git-repot.

### 3. Build project

Git Bash:

```bash
./mvnw clean package
```

Efter en lyckad build skapas:

```text
target/paul-marie-andreas-upg3.war
```

### 4. Start WildFly

Gå till WildFlys `bin`-mapp.

Git bash:

```bash
cd /c/wildfly/wildfly-41.0.1.Final/bin
./standalone.bat
```

WildFly körs därefter på:

```text
http://localhost:8080
```

### 5. Deploy application

När projektet har byggts finns WAR-filen här:

```text
target/paul-marie-andreas-upg3.war
```

Starta WildFly och öppna sedan en ny terminal i projektets rotmapp.

Med Git Bash kan WAR-filen kopieras till WildFly med:

```bash
cp target/paul-marie-andreas-upg3.war /c/wildfly/wildfly-41.0.1.Final/standalone/deployments/
```

Ändra sökvägen om WildFly är installerat på en annan plats.

WildFly upptäcker WAR-filen automatiskt och deployar applikationen.

När deploymenten lyckats skapas:

```text
paul-marie-andreas-upg3.war.deployed
```

i WildFlys `standalone/deployments`-mapp.

### 6. Test application

Den nuvarande test-endpointen finns på:

```text
http://localhost:8080/paul-marie-andreas-upg3/rest/hello
```

För att testa query parameters:

```text
http://localhost:8080/paul-marie-andreas-upg3/rest/hello?name=Andreas
```

Bör få tillbaka något sånt här:

```json
{
  "hello": "Andreas"
}
```
